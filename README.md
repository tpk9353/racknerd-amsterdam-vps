## 2 GB 到底能跑什么

能跑得舒服的：

- 日 PV 几千的 WordPress 站，Nginx 加一层缓存，2 GB 足够
- WireGuard 或 OpenVPN，个人加几台设备同时在线没压力
- Python 爬虫、定时任务、Telegram bot 这类常驻小进程
- 自建 DNS 解析器、监控探针、状态页
- 轻量 seedbox，5 TB/月相当于每天 165 GB 的平均用量
- 一两个人的开发测试环境，跑 Docker 起几个容器
- 几个人一起玩的 Minecraft 服

跑不动的：

- 数据库并发写密集的业务，2 GB 内存会先撑爆
- 视频转码，CPU 和内存都不够
- 同时跑十几个容器加一堆中间件
- 需要严格 SLA 的生产业务

内存是这台机器的硬上限，不是 CPU。工作集一旦溢出到 swap，KVM 上没配 swap 的话 OOM killer 会开始挑进程杀。想清楚你要跑的东西峰值吃多少内存，再决定买 2 GB 还是往上走。

**没有 Windows。** 阿姆斯特丹这条线只出 Linux。Windows VPS 是另一条产品线，价格另算，荷兰没有。

**没有 AMD Ryzen 线。** Ryzen 3900X 和 7950X 加 NVMe 那批高性能机器在纽约、西雅图、达拉斯、圣何塞，阿姆斯特丹暂未上线。要跑编译、数据库这类吃单核的活，荷兰节点只能选 Xeon 标准线。

**100% uptime 只覆盖电力。** 官方承诺的是电力可用性，网络不在这条承诺里。实际网络表现不错，但合同层面不等同。业务收入跟在线率直接挂钩的话，这个价位本来也不该承担那种责任。

**控制面板的说法有两版。** 早期资料写的是 SolusVM，界面偏老；官方特价页现在标注的是 KVM / ctrl 面板，支持重装、VNC 控制台、防火墙规则和一键应用。以开通后实际拿到的为准。账单和账户始终在 my.racknerd.com 的 WHMCS 门户，和 VPS 控制面板是两套登录。
